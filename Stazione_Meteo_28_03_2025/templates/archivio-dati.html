API per Sviluppatori

Accedi ai nostri dati meteorologici tramite API RESTful. Ideale per integrare i dati nei tuoi progetti o applicazioni.

GET https://api.stazionemeteo.itisdelpozzo.edu.it/data/temperature/daily?from=2025-01-01&to=2025-02-25

L'accesso all'API è gratuito per usi educativi e di ricerca. Registrati per ottenere la tua API key.
